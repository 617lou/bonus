# 小小星球 · 行为奖励

给小朋友用的行为奖励记录页：完成每日好习惯攒小星星，攒够了去许愿池兑换愿望。
单个 HTML 文件，无构建、无依赖、无后端，数据存在浏览器 localStorage。

## ⚠️ 必须通过网址打开

把 `index.html` 当附件发到微信里点开是**没法用的**——微信的文件预览器不执行 JavaScript，
页面只会显示静态外壳：行为项目是空的，底部 tab 也点不动。这不是代码问题，任何写法都绕不过去。

同理，iOS 上「用其他应用打开」也没有可用的浏览器选项；Android 可以选 Chrome 打开本地文件，
但那只是临时验证手段，数据同样存不住。

**正确用法**：部署成 http(s) 网址，在微信里点链接打开，然后「添加到主屏幕」当 App 用。

## 部署到 GitHub Pages

本仓库已按 Pages 的根目录布局组织（`index.html` 在根目录）。

1. 在 GitHub 新建一个空仓库（不要勾选自动生成 README）
2. 推送本仓库（见下方命令）
3. 仓库 Settings → Pages → Build and deployment → Source 选 `Deploy from a branch`，
   Branch 选 `main` / `/ (root)`，保存
4. 一分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`

```bash
git remote add origin git@github.com:<你的用户名>/<仓库名>.git
git branch -M main
git push -u origin main
```

固定用同一台手机、同一个浏览器、同一个网址打开，记录才会持续累积。

## 使用

| 页面 | 说明 |
|---|---|
| 今天 | 点右侧 `＋1 ⭐` 打卡，每项每天只能奖励一次；再点一次可取消 |
| 今天 | `额外表扬 +1` / `记录需要改进 −1`，都要写一句具体原因 |
| 账本 | 全部收支流水与累计统计 |
| 许愿池 | 添加愿望并设定所需星星数，攒够后可兑换（兑换会扣减可用星星） |
| 统计 | 近 7 天净得星星、本周各习惯完成率 |
| 设置 | 改本周目标；增删改每日行为项目（名称 / 分类 / 图标） |

计算口径：

- **可用星星** = 累计获得 − 行为扣除 − 愿望兑换。扣星有保护，余额最低为 0
- **净得星星**（今日 / 本周 / 近 7 天）= 获得 − 行为扣除，**不减**愿望兑换
  ——兑换是奖励的消耗，不是负面行为
- 「今天」按**本地日期**划分，不是 UTC。否则在东八区，早上 8 点前的打卡会被算进前一天

## 数据备份

微信「清理缓存」、换浏览器、换手机都会清空 localStorage 里的记录，目前没有导出功能。
重要的阶段性记录建议自行截图留存。

## 本地开发

改动后跑一遍冒烟测试（Node 18+，不需要安装任何依赖）：

```bash
node tools/smoke.mjs
```

77 项断言，覆盖：脚本语法解析、6 个预设项目渲染、打卡与取消、tab 切换与高亮、
增删改行为项目与愿望、自定义弹层（替代 `dialog` / `prompt` / `confirm`）、
localStorage 抛错或为 `null` 时的降级、脏数据容错、本地日期分组。

测试用 Node 内置的 `vm` + 按 HTML 真实 id/class 构建的最小 DOM 桩，
验证的是 JS 逻辑与容错路径，**不等于真机浏览器渲染**——CSS 布局仍需实际打开确认。

也可以指定其他页面文件：`node tools/smoke.mjs path/to/page.html`

## 兼容性

刻意避开了微信 webview 里容易踩的坑：不用可选链 `?.`（老 X5 内核会当语法错误，
一崩就是整页）、不用 `<dialog>.showModal()`（iOS 15.4 以下没有）、不用 `prompt` /
`confirm`（WKWebView 不实现）、不用 `Intl`（老内核 ICU 缺失时日期会退化）、
CSS `min()` 带 `width/max-width` 降级。

页面顶部内置自检提示：脚本完整跑完会自动消失；如果卡在「脚本已开始执行」说明中途崩了，
会同时弹出红色报错条并带行号；如果显示「脚本未执行」说明当前环境禁用了 JavaScript。
